# Task Management System

## Project Description
The Task Management System is a Java console-based program created for CSCI 1301 Programming Principles I. It allows users to create, view, search, complete, remove, save, and load tasks. This project demonstrates core programming concepts from the course through a practical, well-organized application.

## Features and Functionality
- Add a new task
- View all tasks
- Search for tasks by keyword
- Mark a task as complete
- Remove a task
- Save tasks to a text file
- Load tasks from a text file

Each task stores:
- Title
- Description
- Category
- Priority
- Due date
- Completion status

## How to Run the Program
1. Open the project in Eclipse or another Java IDE.
2. Compile all Java files in the `src` folder.
3. Run `Main.java`.
4. Follow the on-screen menu prompts to manage tasks.

## Concepts from CSCI 1301 Used
This project applies several concepts from Programming Principles I, including:
- Variables, data types, and expressions
- Conditional statements using `if/else` and `switch`
- Loops using `while` and `for`
- Methods with parameters and return values
- String processing and comparison
- ArrayLists for data storage
- Classes and objects
- Encapsulation with private fields and public methods
- Exception handling with `try/catch`
- Text file input and output

## Reflection

For my honors project in CSCI 1301 Programming Principles I, I created a Task Management System in Java. The program is a console-based application that allows users to add, view, search, complete, remove, save, and load tasks. What made this project useful was that it brought together many of the ideas from class into a single, complete program rather than keeping them separate in smaller assignments.

The concepts I strengthened the most were methods, classes, and objects, ArrayLists, file handling, and exception handling. Splitting the program into "Main", "Task", and "TaskManager" helped me understand program structure more clearly because each class had its own role. That made the code feel more organized and easier to follow. I also got more comfortable using methods to break the program into smaller pieces, which made the overall design cleaner and easier to manage.

I did not run into any major problems while working on the project, but it still helped me improve the way I think through code. Even simple features required attention to detail, especially when handling user input and task numbers, and ensuring the program handled invalid entries without crashing. Adding file input and output also made the project feel more complete, as it allowed the data to carry over between runs rather than disappearing when the program ended.

This project connects to future programming courses because it reinforced the importance of writing code in a structured and logical way. It also gave me more practice with organizing data, using objects to model information, and designing a program so that different parts work together instead of everything being placed in one file. Those are skills that will matter even more in future courses as programs become larger and more detailed.

Some features I could see myself adding are task editing, sorting them by priority or due date, and creating a graphical user interface. Overall, this project helped me build more confidence with the main ideas from CSCI 1301 and showed me how those concepts can be used in a full program that actually feels practical.
