# Task Management System

## Project Description
The Task Management System is a Java console-based program created for CSCI 1301 Programming Principles I. It allows users to create, view, search, complete, remove, save, and load tasks. This project demonstrates core programming concepts from the course through a practical, well-organized application.

## Features and Functionality
- Add a new task
- View all tasks
- Search for tasks by keyword
- Mark a task as complete
- Remove a task
- Save tasks to a text file
- Load tasks from a text file

Each task stores:
- Title
- Description
- Category
- Priority
- Due date
- Completion status

## How to Run the Program
1. Open the project in Eclipse or another Java IDE.
2. Compile all Java files in the `src` folder.
3. Run `Main.java`.
4. Follow the on-screen menu prompts to manage tasks.

## Concepts from CSCI 1301 Used
This project applies several concepts from Programming Principles I, including:
- Variables, data types, and expressions
- Conditional statements using `if/else` and `switch`
- Loops using `while` and `for`
- Methods with parameters and return values
- String processing and comparison
- ArrayLists for data storage
- Classes and objects
- Encapsulation with private fields and public methods
- Exception handling with `try/catch`
- Text file input and output
